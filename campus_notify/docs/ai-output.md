# AI Output

AI menghasilkan rancangan PushService yang mencakup:

1. Request notification permission.
2. Mengambil FCM token menggunakan getToken().
3. Memantau perubahan token menggunakan onTokenRefresh.
4. Menampilkan local notification ketika foreground.
5. Menangani onMessageOpenedApp.
6. Menangani getInitialMessage().
7. Subscribe ke topic pengumuman-kampus.
8. Background handler menggunakan @pragma('vm:entry-point').

Output lengkap AI disimpan sebagai bagian dari dokumentasi praktikum.
